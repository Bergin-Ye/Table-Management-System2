## 每张文件的数据构成（14 行）

| 内容 | 说明 |
|------|------|
| 1 个「同编号多行」单据 | 编号 `CG-RT-001`，3 行明细 → 导入合并为 1 单 |
| 6 个单行单据 | `CG-RT-002` ~ `CG-RT-007` |
| 1 个空编号行 | 自动回退编号 `IMP{时间戳}{序号}` |
| 1 个特殊字符编号 | `CG-RT-008-%.（）`（含 `%`、`. `、全角括号） |
| 1 个空单元格覆盖 | `CG-RT-009`（部分字段留空） |
| **第 14 行（失败行1）** | `数量 = abc`（非法数字）→ 报"数量格式错误" |
| **第 15 行（失败行2）** | `日期` 留空 → 报"日期不能为空" |

> 注：若某单据**没有「数量」明细字段**（如外购入库/产品入库/其他入库等），第 14 行的非法数字不会触发失败，该行会成为成功单（导入 11 单、1 失败）。

## 预期导入结果

- 明细**含「数量」**字段的单据（销售订单/采购申请/采购订单/其他出库/调拨单）：**10 成功 / 2 失败**
- 明细**不含「数量」**字段的单据（销售出库/外购入库/生产领料单/产品入库/其他入库单）：**11 成功 / 1 失败**

> 行14 的非法数字 `数量=abc` 只有在明细有「数量」字段的单据里才会触发"数量格式错误"；无「数量」字段的单据该行数据不写入文件，转为正常成功单据。

## 手动测试建议流程

1. 前端登录（admin/admin123 或 user1/123456）。
2. 进入某单据页 → 点「导入」→ 选对应 xlsx → 查看导入结果弹窗（成功单据/数据行/失败行明细）。
3. 点「导出」→ 下载文件 → 与原始文件对比，应可 1:1 还原。
4. 下载的导出文件再次导入，应能还原为相同单据。
