# ERP 单据管理系统

一个纯单据管理的进销存系统：10 种业务单据各自独立增删改查，无跨表单业务逻辑、无库存计算。采用**通用单据引擎**架构——全系统只有 `doc_head`（单据头）+ `doc_detail`（明细行）两张物理单据表，所有单据差异由**字段配置 JSON** 描述，前端、后端、导入导出三端共用同一份配置。

- 界面风格：Apple 苹果风格 · 白色 · 液体玻璃（玻璃拟态）
- 支持：登录 + RBAC 权限、Excel 导入导出、全局模糊搜索、列显示选择

## 功能特性

| 功能 | 说明 |
|------|------|
| 10 种单据 CRUD | 销售订单 / 销售出库 / 采购申请 / 采购订单 / 外购入库 / 生产领料单 / 产品入库 / 其他出库 / 其他入库单 / 调拨单，各自独立新增/编辑/删除/查看 |
| Excel 导入 | 同编号多行合并成一单；空编号行自动回退编号 `IMP{时间戳}{序号}`；逐行失败报告；编号重复整组跳过 |
| Excel 导出 | 按当前搜索条件导出，列 = 配置全部字段；导出文件再次导入可 1:1 还原 |
| 全局模糊搜索 | 一个搜索框，模糊匹配**头部 + 全部明细行**字段值，命中明细即返回整单 |
| 列显示选择 | 勾选要显示的列并保存偏好，**按用户独立持久化** |
| 复制单据 | 操作列「复制」→ 打开新增弹窗并**回填当前行全部信息**（编号自动清空引导填新号），快速生成近似单据 |
| 批量删除 | 表格勾选多行 → 工具栏「批量删除」一键删除 |
| RBAC 权限 | 管理员 / 普通用户按菜单授权；普通用户不可见「系统管理」，直调 ADMIN 接口返回 403 |

## 快速启动

### 1. 准备数据库

```bash
mysql -uroot -phaoyu2026 < backend/src/main/resources/sql/init.sql
```

> 重复执行会因外键依赖顺序报错，请勿重复执行。默认账号见下表。

### 2. 启动后端（端口 8080）

```bash
cd backend
mvn spring-boot:run
# 或打包后运行
mvn clean package && java -jar target/erp-backend-1.0.0.jar
```

> 需 JDK 21。若系统默认 `java` 为 JDK 1.8，请先 `export JAVA_HOME="C:\Program Files\Java\latest\jdk-21"`。

### 3. 启动前端（端口 5173，`/api` 代理到 8080）

```bash
cd frontend
npm install
npm run dev
```

访问 http://localhost:5173

## Excel 导入导出约定

- **导入**：读取第一个 sheet，表头行取第一行；列与字段配置的 `excelLabel`（去空白）或 `key` 匹配。
- **同编号多行**：按编号分组合并为一单（头部取组内第一行非空值，其余行依次为明细行）。
- **空编号行**：各自独立成单，自动生成回退编号 `IMP{yyyyMMddHHmmss}{序号}`。
- **编号重复**：该组整单跳过，失败原因"编号已存在"。
- **失败行**：不中断整个文件，逐行报告（Excel 行号 + 原因）。
- **导出**：按当前 `keyword` 筛选条件导出；每个单据每条明细输出一行，头部字段每行重复携带；导出文件再次导入可还原。
